# SoundHaus (사운드하우스)

**유튜브를 틀면서 곡마다 바로 녹음.**

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

[**▶ 바로 써보기**](https://samcheonghaus.github.io/SoundHaus/) · [English README](./README.md)

SoundHaus는 **HTML 파일 하나**로 동작하는 녹음 도구입니다. 유튜브 주소를 붙여 넣으면 영상이 SoundHaus 안에서 재생되고, 곡이 시작하는 순간부터 끝나는 순간까지 정확히 녹음해 **MP3 · WAV · MP4**로 저장합니다. 설치도, 계정도, 서버도 필요 없습니다.

## 사용 방법

1. [samcheonghaus.github.io/SoundHaus](https://samcheonghaus.github.io/SoundHaus/) 를 크롬이나 엣지에서 엽니다.
2. 유튜브 영상(또는 재생목록) 주소를 **붙여 넣습니다** — 바로 불러옵니다.
3. **[● 녹음 시작]** → 뜨는 창에서 **[공유]** 한 번.
4. 곡이 끝나면 자동으로 멈춥니다. 목록에서 **MP3로 저장**.

## 기능

- **곡 단위 정확한 녹음** — 무음으로 추측하지 않고, 플레이어가 알려 주는 재생·일시정지·끝 신호로 시작과 정지를 맞춥니다.
- **재생목록 한 번에** — "재생목록 끝까지"를 고르면 곡마다 따로, **영상 제목으로 파일 이름**을 붙여 녹음합니다 (`01 곡 제목.mp3` …).
- **플레이어 조작** — ⏮ ▶ ⏭ 버튼이나 영상 자체로 조작. 일시정지하면 녹음도 멈췄다가 이어집니다. 녹음 중 다음 곡으로 넘기면 앞 곡은 "일부만"으로 표시됩니다.
- **깨끗한 디지털 녹음** — 스피커·마이크를 거치지 않아 PC 볼륨이나 주변 소음과 무관합니다.
- **저장 형식** — MP3(128~320kbps), 무손실 WAV, 영상 함께 녹화 시 MP4(플레이어 영역만 잘라서).
- **모두 MP3로 저장** — 폴더를 한 번 고르면 재생목록 전체를 한꺼번에 저장.
- **앞뒤 무음 자동 자르기**, **마이크 함께 녹음**(노래·연주 따라하기).
- **다른 탭·프로그램 녹음** — 유튜브가 아닌 사이트나 앱(멜론 등) 소리도 녹음. 소리가 나면 시작하고 무음 2초면 정지합니다.
- 녹음 중에는 탭 제목에 **● 빨간 점과 시간**이 표시되어 다른 탭에서도 상태를 확인할 수 있습니다.
- 한국어 / English.

## 알아 둘 점

- **크롬 또는 엣지(PC)** 에서 동작합니다.
- 유튜브는 내 PC에서 파일을 직접 연 페이지(`C:/…`) 안에서는 재생을 막습니다. **인터넷 주소(GitHub Pages)로 열어 주세요.** 다른 탭 녹음 기능은 파일로 열어도 됩니다.
- 올린 사람이 다른 사이트에서의 재생을 막아 둔 영상은 SoundHaus 안에서 재생되지 않습니다. 이때는 [다른 탭·프로그램 녹음]으로 유튜브 탭을 녹음하세요.
- 영상 앞에 광고가 나오면 광고 소리도 함께 녹음될 수 있습니다.

## 저작권 안내

녹음한 음악은 **개인 감상용으로만** 사용하세요. 저작권이 있는 음악을 다시 올리거나 배포하면 저작권법 위반이 될 수 있으며, 유튜브 이용약관도 함께 확인해 주세요. 녹음 파일은 내 컴퓨터 안에만 있고 어디에도 업로드되지 않습니다.

## 기술

단일 HTML 파일 + 순수 JavaScript.

| 구성 요소 | 용도 |
|---|---|
| YouTube IFrame Player API | 영상 재생과 재생 상태 신호 |
| Screen Capture API (`getDisplayMedia`) | 탭의 소리(와 영상)를 디지털로 받기 |
| Web Audio · AudioWorklet | 원음(PCM) 녹음, 소리 크기 표시 |
| MediaRecorder · Region Capture | MP4 영상 녹화 (플레이어 영역만) |
| [lamejs](https://github.com/zhuker/lamejs) (LGPL-3.0) | MP3 변환 — 처음 MP3로 저장할 때 CDN에서 불러옴 |
